# 校园活动管理系统 V1.0

## 1. 项目简介

校园活动管理系统用于支持学校活动的发布、查看和报名管理。

V1.0 面向两类用户：学生和活动组织教师。当前版本优先保证核心业务流程能够完整运行：教师发布活动，学生查看活动并报名，教师查看报名学生。

本阶段按照软件工程流程推进，先明确项目需求和范围，暂不编写业务代码。

## 2. 用户角色

### 学生

学生可以注册、登录、查看活动、报名活动以及管理自己的报名记录。

### 活动组织教师

活动组织教师可以登录、发布和管理自己创建的活动，并查看报名学生。

## 3. V1.0 功能范围

### 学生功能

- 注册
- 登录
- 查看活动列表
- 查看活动详情
- 报名活动
- 查看我的报名
- 取消报名

### 教师功能

- 登录
- 发布活动
- 查看自己发布的活动
- 修改活动
- 关闭活动
- 查看报名学生

## 4. 核心业务流程

1. 活动组织教师登录系统。
2. 教师发布活动，并设置活动信息和人数上限。
3. 学生注册并登录系统。
4. 学生查看活动列表和活动详情。
5. 学生选择活动并提交报名。
6. 系统校验报名条件，报名成功后记录学生的报名信息。
7. 教师查看自己发布的活动及报名学生。

## 5. 重要业务规则

1. 学生不能重复报名同一个活动。
2. 活动人数达到上限后，不能继续报名。
3. 已结束的活动不能报名。
4. 只有活动组织教师可以发布活动。
5. 教师只能管理自己发布的活动。

## 6. 当前版本明确不实现的功能

V1.0 暂不实现以下功能：

- 签到
- 评论
- 消息通知
- 推荐算法
- 积分

除上述范围外，暂不主动增加其他扩展需求。
